最初に読む順番：①準備②初期設定③現在の入力④将来の比較⑤保存

01 / QUICK STARTまず行うこと

最初は「現在」の会社情報を入力します。将来の年だけを先に入力すると、基準が分からなくなるため、現在値を作ってから将来へ進みます。

用意する資料

経審通知書、完成工事高・元請完成工事高・売上高の資料、決算書、技術職員の資格区分、社会性 W に関係する加入・認証・営業年数の情報。

数字の単位

工事高・売上高と通常の入力欄は画面の表示単位に従います。決算書入力では資料に合わせて円・千円・万円を選び、単位を混在させません。

  1. ログインする

    ログイン画面で、管理者から案内された ID とパスワードを入力して ログイン を押します。ログイン後にこのマニュアルの手順へ進みます。

  2. シミュレーターを開く

    このページ上部の「シミュレーターを開く」から、現在のサイトと同じ起点で開きます。マニュアルへのリンクはアプリ画面の左側結果欄の下にもあります。

  3. 初期設定を確認する

    上部の ⚙ 初期設定 を開き、計画期間、目標ランク・必要 P 点、売上成長率、Y 点計算モデル、入力モードを確認します。

  4. 現在を選ぶ

    年タブの 現在 を選び、4つのカテゴリを順に入力します。PDFを使うときも取込先は現在です。

  5. 将来年を調整する

    現在の入力を以降の年へコピーしてから、年ごとの計画を編集します。P点が 未算定 のときは、詳細財務の入力不足を確認します。

  6. 必要な案をシナリオ保存する

    ➕保存 で名前を付けます。「現状維持」「採用1名」など条件が分かる名前にすると比較しやすくなります。

02 / SCREEN MAP画面の見方

画面は、左側の結果とグラフ、右側の入力エディターに分かれています。デスクトップでは左側の結果欄が見える状態で、右側の入力部分だけがスクロールします。

場所役割
上部ヘッダー⚙ 初期設定、現在と目標年のランク・P点、シナリオ選択、➕保存、リセット。
年タブ現在と 1年後〜10年後。点数、ランク、基準から変更があるかを確認できます。
左側の結果選択中の年の P 点、基準との差、目標ランクまでの距離、年別グラフ。左側下部に操作マニュアルへのリンクがあります。
右側のカテゴリ工事高・売上高、技術力 Z、財務 Y・X2、社会性 Wの4タブ。

スマートフォンでは：年タブの代わりに 編集中 の年選択ドロップダウンを使います。左側の結果の下に入力エリアが続き、カテゴリタブは横幅に合わせて表示されます。

03 / SETTINGS初期設定をする

ヘッダーの ⚙ 初期設定 を押して設定欄を開きます。設定を変えると計算対象の期間や表示結果が変わるため、現在の入力を作る前に決めます。

設定項目何を決めるか覚えておくこと
目標年数現在から何年後まで比較するか1〜10年後。期間を短くしても、すでに作った将来データは内部に残ります。
目標ランク / 必要 P 点目標ランクと基準点ランクを選ぶと点数が入り、必要なら点数を直接変更できます。
売上成長率（年）将来の売上・入札活動の前提成長なし（0%）から +200%/年までの選択肢があります。手動入力した将来の実績値を勝手に置き換える設定ではありません。
Y点計算モデル簡易・近似か、詳細・公式式か簡易は4指標の参考推計。詳細は実経審8指標です。詳細では原資料の値が揃うまで Y・P が未算定になることがあります。
入力モード売上を直接入力するか、入札活動から推計するか手動は完成工事高・元請完成工事高・売上高を入力。自動は入札件数・落札率・平均金額から推計します。
詳細モデルの表示：詳細モデルの初期状態では、原資料に基づく詳細財務値が揃わないため、Y・P は 未算定 と表示されます。操作確認だけなら「簡易・近似（4指標）」を参考値として使えます。簡易モデルの数字を正式な審査結果として扱わないでください。

04 / CURRENT「現在」の入力を始める

年タブで 現在 を選びます。右側の4カテゴリを開き、資料を見ながら入力します。入力は自動保存されますが、保存したい条件は別途シナリオにも保存してください。

入力順

工事高・売上高 → 技術力 Z → 財務 Y・X2 → 社会性 W。順番は固定ではありませんが、現在値を先に揃えると将来コピーを使いやすくなります。

点数の読み方

P点の内訳は X1・X2・Y・Z・W です。各カテゴリの点数は入力の確認用で、P点は選択中の年に対して表示されます。

初期値に注意：画面に値が入っていても自社の実績とは限りません。資料を確認し、会社の実績・計画へ置き換えてください。

05 / PDF IMPORT経審PDFを取り込む

現在の経審通知書などから読み取った値を確認して、現在の入力へ反映できます。画面の PDF取込（現在のみ） は 現在 で行います。将来年の入力欄で使う操作ではありません。

画像PDF用 OCRサーバー設定（任意）

文字PDFはこの設定なしで読み取れます。画像PDFでOCRを使う場合だけ設定します。

  1. OCRサーバーURLに https://ai-interview.replit.app/api/keishin-ocr を入力します。別の管理者案内がある場合は、その完全なURLを使います。
  2. OCR利用コードに管理者から案内されたコードを入力します。コードはこのブラウザーのセッション中だけ使われ、シナリオには保存されません。ページを開き直したときは再入力します。
  3. 経審OCR専用のGemini APIキーは管理者がサーバー側で設定します。ブラウザーへ入力するのはOCR利用コードだけです。設定後も、読み取り結果を原本と照合してから反映します。

  1. 現在を選ぶ

    年タブの 現在 を選び、右側の PDF取込（現在のみ） を開きます。業種を資料に合わせます。

  2. PDFを選択する

    建設工事の種別を選び、PDFを読み込みます。読み取り結果の欄では、読み取り値、単位、出所、通知書の参照点を確認します。

  3. プレビューを修正する

    必要なら読み取り値を編集し、反映する項目のチェックを外します。会社名、期、業種、単位、数値を原本と照合します。

  4. 確認して反映する

    会社・期・業種・単位・読取値を原本と照合したにチェックを入れ、確認して反映・実績保存を押します。確認前は反映できません。

  5. 将来へコピーして編集する

    反映後、▶ 「現在」を以降の年にコピーを使います。コピー後に1年後、2年後など各年を選び、計画に合わせて手動で編集します。

読み取り結果は必ず確認：PDFやOCRの値はそのまま採用せず、原本と照合してください。通知書にある評点は参照値として保存されます。

06 / REVENUE工事高・売上高を入力する

手動入力

項目使われる場所入力の考え方
完成工事高X1完成工事高の実績を万円で入力します。
元請完成工事高Z2元請分の完成工事高を万円で入力します。
売上高簡易Yの売上分母など完成工事高とは別に、資料の売上高を入力します。

「経審の平均値を直接入力する（X1点・Z2点で使用）」を使う場合は、通知書の2年平均または3年平均を選び、完成工事高と元請完成工事高の平均値を入力します。平均値を指定すると X1・Z2 はその値を使います。

自動（入札活動から推計）

入力モードを自動にすると、対象業種、スタッフ数、1人あたり月間入札件数、工事割合、落札率、平均落札金額を使って推計します。詳細表示では工事と役務・物販を分けて確認できます。工事分は完成工事高（X1）、工事と役務・物販の合計は売上高の推計に使われます。

自動モードで推計した売上は、詳細財務の原資料入力を自動更新しません。詳細Yを使う場合は、右側の「財務の詳細計算と実績照合」で決算データを入力してください。

07 / TECHNICAL技術力 Zを入力する

技術力 Zでは、対象業種の技術職員の資格区分と人数を入力します。画面は Z1（技術職員）と Z2（元請完成工事高）を表示し、Z点へ反映します。

入力欄の例確認すること
1級技術者（監理技術者資格者証あり）資格区分と人数が資料に一致しているか。
1級技術者、管理補佐、基幹技能者同じ人を重複して数えていないか。
2級技術者、その他対象業種と申請前提を確認して入力する。

技術職員は1人につき2業種までの申請を前提にした表示です。実際の資格区分・業種の扱いは手元の資料と申請条件に合わせてください。

08 / FINANCE財務 Y・X2を入力する

詳細モデルを選んだときは、右側の 財務の詳細計算と実績照合 を開きます。この欄は現在だけでなく、選択した全年度で使えます。

まず入力する基本値

決算書の売上高、売上総利益、経常利益、営業利益、減価償却実施額、支払利息、受取利息配当金、純資産、負債総額、総資本、固定資産、利益剰余金などを、表示された期間へ入力します。営業キャッシュフローは、各期の経審用CF、2期平均の直接入力、内訳から計算、簡易推計から選びます。

決算書を入力するとき

  1. 表示単位を決める

    「表示単位」で千円または万円を選び、手元資料に合わせます。単位を変更したときは、表示値が変換されるため確認します。

  2. 当期・前期を入力する

    2期平均が必要な項目は前期も入力します。原資料の期間、決算区分、法人・連結の条件を確認します。

  3. 計算方法を確認する

    営業CF、自己資本、利益の取り方を選び、入力不足・エラー・対象外の表示を確認します。

  4. 内容を確認済みにする

    資料を照合したら 入力内容を確認済みにする を押します。必要なら通知書の実績との照合履歴も保存します。

Y・X2が未算定になる場合：詳細計算に必要な原資料の項目が不足している、入力エラーがある、対象外の決算区分・期間である、などが考えられます。パネルに表示された不足項目を埋めてください。

簡易モデルと詳細モデルの違い

「簡易・近似（4指標）」は操作や条件比較のための参考推計です。「詳細・公式式（実経審8指標）」は詳細財務入力を使います。詳細モデルを選んだ状態で、簡易モデル用の旧来の利益率・自己資本・負債・支払利息欄を変えても、詳細財務計算の入力にはなりません。詳細計算の元資料は詳細パネルへ入力します。

09 / SOCIAL社会性 Wを入力する

Wは、福利厚生・人材育成、営業継続、防災協力、法令遵守、経理体制、研究開発、建設機械、ISO等の入力から計算されます。画面の まず入れる、会社の基本情報、該当するときだけ を順に確認します。

  • まず入れる：建退共、退職一時金・企業年金、法定外労災、ISO 9001、ISO 14001、エコアクション21など。
  • 会社の基本情報：建設業の営業年数、監査の受審状況、公認会計士等の人数、2級登録経理試験合格者数、対象建設機械の台数。
  • 該当するときだけ：若手技術者、技能向上、認定・履歴、再生・更生、防災協定、処分状況、研究開発費など。

W点を手動で入力するを使うと、下のチェック項目を使わず、入力した点数をW点として採用します。手動入力を解除すると、取組項目から計算します。W評点とPへの反映は別の表示です。

10 / FUTURE PLAN将来計画を作って比較する

現在を基準に、1年後から10年後までの入力を持てます。年を選ぶと、その年の点数と入力状態に切り替わります。

  1. 計画期間を選ぶ

    上部の 計画期間 で何年後まで表示するかを選びます。

  2. 現在を以降の年へコピーする

    ▶ 「現在」を以降の年にコピーを使うと、現在を起点に将来年を作れます。すでに入力した将来データは上書きされるため、確認してから実行します。

  3. 年ごとに編集する

    1年後、2年後などを選び、売上、技術者、財務、社会性を計画に合わせて編集します。年タブの変更マークは、ページ・シナリオを読み込んだときの基準から変更があることを示します。

  4. グラフと基準差を見る

    左側の P 点、グラフ、基準差、目標までの点数を確認します。基準はページを開いた時点、またはシナリオを読み込んだ時点の入力です。

期間を短くしたとき：表示する年数を減らしても、背後にある将来年のデータは保持されます。あとで期間を長く戻したときに、残っている将来入力を確認できます。

現状維持

現在をそのままコピーし、基準となるシナリオとして残します。

一つの施策

採用、売上、制度加入など一つだけを変えて差を見ます。

実行案

複数の施策を組み合わせ、目標年の点数を確認します。

11 / SAVE & RESET自動保存・シナリオ・リセット

自動保存

入力中の状態はブラウザーの保存領域に自動保存されます。保存先はブラウザーとサイトの組み合わせごとです。別のブラウザー、別の端末、別のサイトの起点では同じデータが表示されないことがあります。

名前を付けて保存

  1. ➕保存を押す

    上部ヘッダーのボタンを押し、シナリオ名を入力します。

  2. 選択欄で確認する

    — シナリオ —の選択欄に名前が表示されます。名前を選ぶと、その時点の目標・期間・各年の入力を読み込みます。

  3. 必要なら名前を変更・削除する

    読み込んだシナリオには名前変更と削除のボタンが表示されます。削除は元に戻せないため、確認してから行います。

リセット

リセットは現在の編集内容を初期状態へ戻し、自動保存された編集データを消します。保存済みのシナリオは残ります。リセット後に必要なシナリオを選び直してください。

12 / TROUBLESHOOTING困ったとき

症状確認すること
P点が「未算定」詳細モデルで、Y・X2の原資料が不足していないか確認します。財務パネルの不足項目、入力エラー、対象外表示を確認してください。
PDFを反映できない現在を選んでいるか、原本確認チェックを入れたか、会社・期などのコンテキストを入力したか確認します。
将来年が変わらないコピー元の年を選んでからコピーを実行し、コピー先の年を選び直します。期間の表示を短くしていないかも確認します。
入力が消えたように見えるブラウザー・サイトの起点が変わっていないか、別シナリオを読み込んでいないかを確認します。保存済みシナリオの選択欄も確認してください。
点数が期待と違う現在か将来か、対象業種、入力モード、平均方法、Y点モデル、W点の手動入力状態を確認します。

13 / FINAL CHECK入力後のチェック

以下は操作の確認用です。チェック状態はこのマニュアルにだけ表示され、シミュレーターの入力や保存には影響しません。

このツールは入力条件を比較するためのシミュレーターです。正式な審査結果、発注機関の格付け、財務・法務上の判断を保証するものではありません。資料の確認と必要な専門家への相談は別途行ってください。

対象：経審スコアシミュレーター ／ このマニュアルはアプリの画面名と操作に合わせた案内です。アプリ更新により表示や名称が変わる場合があります。

マニュアルは現在のサイト起点から相対的にシミュレーターを開きます。入力データはブラウザーとサイトの保存領域に保管されます。
